# Accuracy benchmark results

Canonical contract-vs-behavior accuracy report for the universal data-anomaly detector.
Generated by `python -m tools.benchmark` against a seeded SQLite dataset with **known** planted anomalies. The engine is exercised as a black box via `app.api.container.build_container` (no test doubles for detectors).

- **rows**: 2000
- **seed**: 1234
- **date**: 2026-07-09
- **ground truth**: `truth.json` beside `bench.db` in the run workdir
- **paths**: in-memory `run_scan` and streaming `stream_scan` (separate containers)

## Scoring notes

- **Contract families** (`picklist_invalid`, `required_missing`, `orphan_reference`, `invalid_format`): precision = true-positive findings / all findings of those types. Clean rows are constructed to be contract-clean, so precision is expected to be **1.0**.
- **Statistical family** (`stat_outlier` → `numeric_outlier` / `robust_outlier`): recall vs planted extremes; extra flags go to the honest **extra statistical candidates** bucket (not false positives).
